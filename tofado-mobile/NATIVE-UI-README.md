# Tofado Merchant Mobile — Native UI Edition

This is a full replacement of the production mobile project with a more native mobile visual system inspired by Google, Stripe, and Zoho mobile apps.

Changes: flat mobile surfaces, app-bar actions, native list rows, lighter borders, no gradients, stronger touch targets, cleaner bottom navigation, native login, cleaner dashboard hierarchy.

Run as usual:

```powershell
npm install
npx expo install --fix
npm start
```
